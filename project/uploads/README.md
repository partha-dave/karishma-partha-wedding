# K + P Wedding Website Design Package

Upload this entire folder/ZIP to Claude Design.

Start by telling Claude:

> Use `DESIGN-SPEC.md` as the source of truth. Rebuild my existing wedding website using this design system. Preserve the existing information architecture and real content, but implement the supplied visual language as reusable responsive components. Do not flatten the mockups into images. Build mobile-first, use the supplied SVG assets, and keep the white background dominant.

## Package contents
- `DESIGN-SPEC.md` — comprehensive design and implementation brief
- `code/design-tokens.css` — starter CSS tokens and component treatments
- `assets/svg/` — editable vector doodles/icons
- `assets/references/` — original style reference, if available
- `assets/mockups/` — desktop/mobile design concepts, if available

## Important
The mockups are art-direction references. Their dummy text and generated imagery are not authoritative. The actual site content should come from the existing website/project.

The implementation should reproduce the *system*: white canvas, chunky black display type, ticket cards, angled photos, tape, stickers, handwritten annotations, and restrained pink/yellow/blue/lilac accents.
